Smart Job Application Tracker

About the Project

Smart Job Application Tracker is a backend application developed using Java and Spring Boot to manage job applications efficiently.

Features

- Add new job applications
- View all job applications
- Update existing application details
- Delete job applications
- Store application data in MySQL database

Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- REST API
- Maven

API Endpoints

Method| Endpoint| Description
POST| "/api/jobs"| Add a job application
GET| "/api/jobs"| View all applications
PUT| "/api/jobs/{id}"| Update an application
DELETE| "/api/jobs/{id}"| Delete an application

How to Run

1. Clone this repository.
2. Configure your MySQL database.
3. Set the "DB_USER" and "DB_PASSWORD" environment variables.
4. Run the Spring Boot application.
